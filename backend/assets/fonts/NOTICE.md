Используются ТОЛЬКО для генерации демо-документов (scripts/seed.py), чтобы кириллица
корректно отображалась в PDF. В проде укажите свой шрифт через ENV `DEMO_FONT_PATH`
или установите системный пакет: `apt-get install -y fonts-dejavu-core`.
